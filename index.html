How to use this on iPhone · metric guide · privacy

Open the deployed link in Safari and sign in if requested. Use Share → Add to Home Screen if available. This is a web notebook, not a native radio scanner. GPS needs HTTPS, browser location permission, and may not work in embedded previews; open the link directly. No automatic radio readings or background GPS. Drafts are saved before you leave for Field Test.

RSRP measures signal strength; closer to zero is stronger. RSRQ measures quality; closer to zero is generally better. SNR compares signal with noise; higher is better. Speed and latency reveal actual performance but depend on congestion, test server, device and conditions. Record those separately using your usual speed-test tool—this app does not run a speed test.

RSRP coloring uses a fixed −120 to −80 dBm visual scale, not guaranteed service thresholds. Other metrics scale to the visible samples; compare colors only within the selected metric/network. LTE and 5G are never combined. Sample shading colors only a small area around each observation, not estimated coverage between points. Unmeasured areas remain unmeasured. GPS accuracy is not radio coverage.

No analytics, account data integration or server measurement storage. Optional street tiles disclose the viewed area to OpenStreetMap. Hosting/sign-in still uses normal network requests. Local storage is not encrypted; avoid sensitive notes on shared devices.

Built for deliberate measurements. Never log while driving.
